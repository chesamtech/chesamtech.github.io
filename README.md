# ChesamTech — Personal Portfolio

A responsive, single-page portfolio website built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser. No build tools or package installation are required.

## Before publishing — personalise these details
1. In `index.html`, replace `YOUR_EMAIL@example.com` with your professional email address.
2. Replace the generic LinkedIn URL with your own profile URL.
3. Confirm that the GitHub repository links are public and that the project descriptions accurately reflect what is currently implemented.
4. Add a downloadable CV link if you want employers to download your CV.
5. Consider adding project screenshots after confirming they do not expose credentials, customer data or private information.

## Publish with GitHub Pages
1. Create a new GitHub repository, for example `samuel-njenga-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js` and this README to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site and open the URL shown in Settings → Pages.

## Notes
- The contact button uses a `mailto:` link. It opens the visitor's email app; it does not send messages to a server.
- Google Fonts are loaded online. System fonts are used as fallbacks.
- Project status labels are intentionally conservative; update them as projects progress.
